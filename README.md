# 2027 计算机组成原理知识图谱

本项目包含知识图谱、复习标记、学习计时和章节 PDF。

## Gitee 部署

1. 在 Gitee 个人设置 -> 安全设置 -> 私人令牌 中生成令牌，勾选 projects 权限。
2. 双击项目根目录的 `部署到Gitee.cmd`。
3. 按提示输入 Gitee 用户名、网站仓库名、私有数据仓库名和私人令牌。
4. 脚本会自动创建仓库、上传网站和章节 PDF、初始化云同步数据。
5. 打开 https://gitee.com/你的用户名/网站仓库 页面，点击 `服务 -> Gitee Pages`，选择 `master` 分支部署。
6. Pages 发布后，手机打开 https://你的用户名.gitee.io/网站仓库/。
7. 在网站中点击 `手机同步`，输入 Gitee 私人令牌一次，之后复习进度和学习时长会通过私有数据仓库同步。

## 本地运行

双击 `一键启动.cmd` 可以在本地运行。
